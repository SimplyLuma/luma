# Fedora Silverblue supplies some stock applications as system Flatpaks whose
# bundled runtime bypasses Luma's patched host GTK/libadwaita. Luma ships these
# curated roles as native packages so they consume the exact host toolkit and
# shared window chrome. One entry per line: `<application id> <native package>`.
# Image provisioning removes a system Flatpak only after its native provider is
# already installed or has been requested in the same deployment. User Flatpaks
# and shared runtimes are never touched, and no sandbox theme override is used.
