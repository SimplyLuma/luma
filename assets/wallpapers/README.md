# Project Luma wallpapers

This directory contains Project Luma's source-controlled wallpaper collection.
Assets are installed byte-for-byte without recompression or visual
modification. Prism, Meadow and Ember are exposed through GNOME's standard
wallpaper picker; Prism remains the fresh-profile default.

## Prism

on 2026-08-29. The asset was replaced on 2026-09-11 with a smaller encoding of
the same image, supplied by the project owner.

`luma-mesh-gradient.jpg` is the 7680×4320 JPEG selected on 2026-08-07. It

- SHA-256: `348f890fa6d412e76c0abcddefa287499eb080a897b903c2b8c0898f127f454e`

The separate `luma-prism.png` encoding remains packaged solely for the existing
handheld wallpaper path. It does not add a duplicate picker entry, and it still
carries the pre-2026-09-11 Prism encoding; the handheld path is refreshed
separately with the rest of the phone work.

All assets are approved for Project Luma's internal design builds. Their
public redistribution licenses must be recorded before a public release
artifact is published.
