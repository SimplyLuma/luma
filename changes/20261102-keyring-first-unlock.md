Summary: Unlock saved passwords once, with a switch to never ask again
Details: A device that signs in automatically and was set up earlier now asks for the password in Luma's own sheet at the start of the session, with "Unlock automatically on this TV" (or computer) on by default. Apps no longer show their own password prompt while it is up.
