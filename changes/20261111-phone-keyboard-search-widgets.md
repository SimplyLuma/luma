Summary: Phone keyboard, Search and Home widget fixes
Details: Typing on the on-screen keyboard no longer closes Search. On a phone the keyboard's hide and settings buttons sit below the keys, so it can be put away while typing, and Back puts it away first. Home widget text on larger phones follows the widget size.
