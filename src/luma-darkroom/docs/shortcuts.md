# Darkroom keyboard shortcuts

| Action | Shortcut |
| --- | --- |
| Open, Save, Save As, Export | `Ctrl+O`, `Ctrl+S`, `Ctrl+Shift+S`, `Ctrl+E` |
| Undo, Redo | `Ctrl+Z`, `Ctrl+Shift+Z` |
| Select, Crop, Hand, Zoom | `V`, `C`, `H`, `Z` |
| Brush mask, Healing, Clone | `B`, `J`, `S` |
| Gradient, Eyedropper | `G`, `I` |
| Fit, Actual pixels | `0`, `1` |
| Before and after | `\` |
| Hide or restore panels | `Tab` |
| Brush size | `[` and `]` |
| Exit focused tool | `Escape` |

Canvas shortcuts do not fire while an editable text or numeric field has focus.
