# Current Messages provider integration

Use **core71-message-provider.patch** (singular `message`), generated by
prepare-core-provider-patch.py against the exact current source hash printed by
that tool. **core71-messages-provider.patch** (plural `messages`) is historical,
obsolete, and must not be applied. Neither patch is installed in the shared dirty
Core checkout. MESSAGES-PROVIDER-CHECKPOINT.md records current scope and limits.

The current patch adds explicit selected-phone configuration, account/grant-gated
worker lifecycle, private incoming cache, and existing composer/transmit-worker
queue integration in the one shared Messages app. Without a selection, local
Messages remains available even with older Connect0.7 installed. An invalid
existing selection fails closed. No contacts/calls/RCS features are added.

Current source is unpackaged beyond installed0.7. Exact transformed-source
compilation and isolated method checks are not GTK/device runtime acceptance.
Selection UI, physical listener ownership, real account/device acceptance,
full-history pagination, per-message read/deletion reconciliation and definitive
unknown-send recovery remain open. Do not claim live text sync or successful
carrier sends from synthetic tests.

Account StateChanged/owner loss, grant journal and selection-file notifications
invalidate queued worker results by generation without UI-thread network calls.
Filesystem grant invalidation is conservative and may also invalidate harmless
journal lifecycle changes. Actual GTK event ordering/availability requires a
runtime check before promotion; a dedicated grant-generation signal from the
source-owned pairing broker is preferable when that broker is integrated.
PairedExchange separately checks fresh account authorization after TLS and
inside final journal admission before transmission, and on receipt admission.
No UI generation check claims instantaneous observation of an undelivered OS or
D-Bus event; no account/grant policy bypass is permitted to improve availability.

No package pin, phone runtime, modem service, or shared source was changed.
