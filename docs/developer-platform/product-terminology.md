# Luma product terminology

Use these names in user-facing text, accessibility labels, settings and design
documentation. Product naming is independent of upstream technical identifiers.

| Name | Meaning |
| --- | --- |
| Dash | The collective shell area containing the application dock, clock, quick options and adjacent system controls. Accepted September 7, 2026. |
| Dash Settings | The settings entry for that collective area. |
| Dock | The application-launcher section within the Dash, when referring specifically to that section. |

Dash is the product name for the full area previously discussed as the shelf,
dock/time area, or dock and quick options. Keep stable schema keys and upstream
class names unless a separately reviewed migration requires changing them.
