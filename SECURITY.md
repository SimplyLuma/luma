# Security

For a suspected vulnerability, use GitHub's private vulnerability reporting for this repository when available. If it is unavailable, use the contact route on https://simplyluma.com and request a private security conversation before sharing details. Do not post credentials or exploitable private data in a public issue.

Include the affected component and version, architecture, a minimal reproduction and potential impact. Remove unrelated personal data. Please avoid testing against other people's devices, accounts or production services.

This project is in beta. A source profile or old build is not a guarantee of continued security support. Release and component support information should be checked before relying on a particular build. Signed update metadata and packages are separate from source publication; no signing private keys are distributed in this repository.
